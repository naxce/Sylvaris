Sylvaris design reference

The approved visual source of truth for SylvarisCC, SylvarisTP and SylvarisSettings. All sizes are real pixels, and every value in the token table maps directly to Tokens.qml. Colors shown are the example "warm" palette; real colors come from the active theme's JSON. Add ?wallpaper=/path/to/image.jpg to preview with a real wallpaper. The constellation idea is inspired by ilyamiro/serpantinum.

A compact 460×660 panel that grows to 620×660 for detail views. The demo cycles through three states: compact → Bluetooth orbit (controller view) → device focus.
